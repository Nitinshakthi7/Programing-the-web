# Programming the Web

This repository contains all coursework, assignments, and testing projects completed as part of the **Programming the Web** course. It demonstrates practical understanding of web development basics through individual assignments and a test project.

---

## 📖 Repository Structure

- **main branch**: Includes a test project where a parody GTA 6 website was built to check HTML and CSS functionality and experiment with layout and assets. This was a personal test, not a main creative project, and is purely for checking if various features work in the browser environment.

- **assignments branch**: Contains all course-related assignments and projects. These cover core HTML skills, CSS application, page layout, forms, tables, lists, and site navigation—each demonstrating foundational web development concepts as learned in the course.

---

## 🧩 Skills Demonstrated

- HTML page structuring and semantic elements  
- CSS styling, layout, and visual design  
- Usability and simple site navigation  
- Clean, standards-based code  

---

## 🚩 Note on the GTA 6 Demo

The GTA 6 parody site in the main branch was created solely as a test to verify site-building techniques. It is not an original or portfolio project, nor intended for any real-world use. All content is entirely unofficial and for in-browser experimentation only.
