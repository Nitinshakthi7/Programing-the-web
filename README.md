# Programming the Web – Assignments Branch

This branch contains all assignments and mini-projects completed for the **Programming the Web** course.

---

## 📁 Assignment Folders

- **Book Club Signup**  
  Basic user signup page with semantic HTML and form handling.

- **Bug Code fix**  
  Debugged and improved HTML/CSS code for a sample website.

- **Latte Card**  
  Simple card layout to practice component-based HTML and CSS structuring.

- **Mini Challenges**  
  Collection of small web design and coding challenges from the course—focusing on interactive elements, buttons, and layout training.

- **Perfume Card**  
  Product card mini-project to polish flexbox, grid, and style principles.

- **Social Proof Page**  
  Social review/feedback layout demonstrating advanced structuring, responsive design, and multi-section site composition.

- **The World Ledger**  
  Initial work for a more complex webpage—potentially multi-section or database-driven (in-progress or as a design exercise).

---

## 🌟 Key Concepts Covered

- Semantic HTML structure
- Forms, cards, and reusable components
- Bug fixing and refactoring for clarity
- CSS layout (Flexbox, Grid, responsive design)
- Interactive elements and accessibility
- Best practices: separation of concerns and file organization

---

## 📝 How to Use

Each assignment is organized in its own folder for clarity:
1. Open any folder to view the specific assignment/project files.
2. Most assignments include an `index.html` and supporting CSS.
3. Open `index.html` in your browser to view the project.
